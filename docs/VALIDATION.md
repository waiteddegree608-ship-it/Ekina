# 本轮验证记录

本轮在 Windows 本地开发环境验证。所有测试使用隔离测试数据或 mock，不调用真实模型，不运行远程训练，不连接旧研究数据库。记录不表示所有集成场景都已验证。

| 检查 | 结果 | 覆盖范围 |
| --- | --- | --- |
| Vue / TypeScript 构建 | 通过 | 类型检查与生产静态资源构建 |
| Maven package | 通过 | Java 21 五模块编译与可执行 JAR 打包 |
| Java 科研回归测试 | 107 项通过 | 研究计划、项目、证据、综述、提示词、Skill 加载与工具白名单 |
| Python 文档处理测试 | 11 项通过 | 全文、LaTeX 和论文插图辅助逻辑 |
| 浏览器研究工作台测试 | 通过 | 项目创建、约定/指导、证据链、审查、撤回冲突与重试、刷新、布局、无生活入口 |
